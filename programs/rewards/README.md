# Rewards Program

Planned Solana Devnet settlement responsibilities:

- initialize protocol configuration;
- register reward epochs;
- authorize one reward root per epoch;
- verify worker claims;
- prevent double claims;
- transfer Devnet test rewards from a program-controlled vault.

The MVP should use a minimal Anchor program. No Mainnet deployment or economically valuable token is in scope until the off-chain useful-work pipeline is proven and audited.
